## 🚀 Featured Project: IELTSpeak

A full-stack web app I built to help students prep for the IELTS Speaking test. It uses a conversational AI (**Google Gemini** + **Vapi**) to run a realistic, voice-only mock exam and give detailed feedback.

The stack is **Next.js**, **Supabase**, and **Tailwind CSS**. It's monetized with **Lemon Squeezy** and monitored with **Sentry** and **PostHog**.
