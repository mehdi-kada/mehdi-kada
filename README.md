## 🚀 Featured Project: IELTSpeak - AI-Powered IELTS Speaking Coach

**IELTSpeak** is a full-stack web application I built from the ground up to help students prepare for the IELTS Speaking test. It uses a conversational AI powered by **Google Gemini** and **Vapi** to simulate a realistic, voice-only exam environment and provide detailed, personalized feedback.

The application is built with a modern stack including **Next.js**, **Supabase** for the backend and auth, and **Tailwind CSS** for the UI. To ensure a robust user experience, the application is monetized using **Lemon Squeezy** and includes integrated monitoring with **Sentry** and **PostHog**.
